AEROPROJECTS — SETUP

1. Upload index.html and config.js to a GitHub repository.
2. On GitHub: Settings -> Pages -> Deploy from branch -> main -> /root.
3. GitHub will give you a public website address.
4. Whenever you want to edit your projects, open config.js on GitHub,
   click the pencil/Edit button, change title/description/category/icon/link,
   then commit the change. The website updates automatically.

IMPORTANT:
- You do NOT need to touch index.html for normal project changes.
- Change only config.js.
- Replace the example.com links with your real project links.
